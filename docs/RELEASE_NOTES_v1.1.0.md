# v1.1.0 — RDK S100 实车验证的科目二 LIO 顺序航点控制

## 版本定位

本版本在 v1.0.0 基线上完成了多轮 RDK S100 实车闭环调试。控制器核心已在
当前履带式差速车辆、LIO 定位、现场航点和参数组合下实际运行，现场操作人员
确认最终形态基本可用，可作为当前设备的科目二使用与后续调参基线。

“实车验证可用”仅适用于当前 RDK S100、车辆、场地、LIO、底盘驱动、电池和
参数条件，不代表对其他车辆或场地完成安全认证。

## 主要更新

- `/cmd_vel` 改为可配置的固定频率发布，与 LIO odom 回调频率解耦。
- 增加控制命令租约；超过 `command_hold_timeout_sec` 没有新的可用控制结果时
  发布零速。
- 完善标准 Pure Pursuit 动态前视、参考航向、航点顺序确认、原地对准滞回和
  底盘非零输出下限。
- 控制终端增加航点进度、追踪点、参考航向、横向误差、原始/整形控制量和
  实际发布控制量日志。
- 提供可选停滞检测与控制量提升机制；最终实车 profile 默认关闭。
- 新增本地 WGS84 航点转换工具：读取 `track_output.txt`，支持正北、正东、
  正南、正西及任意初始航向，生成 `watpoints_odom.csv`。

## 当前实车参数基线

- 巡航/最大线速度：`1.5 / 1.5 m/s`
- 最大角速度：`2.0 rad/s`
- 行进最低线速度：`1.0 m/s`
- 行进纠偏/原地转向最低角速度：`0.10 / 2.0 rad/s`
- 动态前视：`8--12 m`
- 中间/最终航点容差：`2.0 / 2.0 m`
- `/cmd_vel` 发布频率：`0.5 Hz`
- 控制命令租约：`4.10 s`
- 行进角速度脉冲：关闭
- 停滞提升：关闭
- GPS/LIO 自动恢复：未启用
- 从路径自动对齐 map/odom：关闭

完整参数见
`src/ugv_subject2_bringup/config/subject2_field_verified.yaml`。

## 验证说明

- 控制器核心来自 RDK 上已经完成构建并进行实车运行的最终现场版本。
- 现场完成了多轮顺序航点闭环测试，最终形态由现场操作人员确认基本可用。
- Pure Pursuit、角速度脉冲、停滞提升和 WGS84 转换器均有自动化测试覆盖。
- 本版本补齐了 v1.0.0 中“尚未完成新控制器实车闭环调参”的限制。

## 已知限制

- 不包含避障；只能在清空障碍物的封闭场地使用，并保留现场急停。
- GPS 接续定位和 LIO 跑飞自动恢复尚未完成。
- 控制器直接读取 `/localization/odom`，不使用 odom 时间戳或新鲜度 guard。
- `0.5 Hz + 4.10 s` 下，完全失去新控制结果后的最坏置零响应可能接近 6 秒；
  不能替代底盘看门狗。
- Ctrl+C 或进程崩溃不保证额外发送最后一帧零速。
- `/cmd_vel` 是速度请求，不是底盘实际速度闭环；电池电压、驱动器死区和
  履带阻力仍会影响实际运动。现场验证使用状态良好的电池。
- 当前发布频率、租约和运动参数不应直接复制到未确认接收策略的其他底盘。
- 雷达六轴全零外参只适用于用户确认的当前安装状态。
- 航点和运动参数只在节点启动时读取，修改后必须重启控制 launch。
